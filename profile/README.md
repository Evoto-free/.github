## 🧠 Overview

Evoto is an AI-assisted photo editor aimed at high-volume portrait and wedding work: it applies skin retouching, face shaping, background cleaning and colour profiles in batch, with every adjustment left as a slider on top of the automatic result. It is developed by Evoto. The product family is positioned as a ai batch retouching toolset for Windows workflows.

Evoto works as a desktop application on Windows 10 and Windows 11 and is installed alongside a host application such as Adobe Photoshop.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🙂 Face Retouching | Skin, eyes, teeth and hair adjustments applied per detected face. |
| 📐 Reshape | Liquify-style proportions driven by sliders instead of manual dragging. |
| 🎨 Colour Profiles | Camera-matched colour and tone profiles applied across a whole shoot. |
| 🧹 Background Cleanup | Removes distracting objects and evens out studio backdrops. |
| 🗂️ Batch Processing | Applies a saved preset to hundreds of frames with per-face detection. |
| 🖥️ Local Rendering | Processing runs on the machine, so originals are not uploaded. |
| 🔄 Plug-in Round-trip | Returns rendered files to Photoshop or Lightroom for final work. |
